# לומדים תמרורים — מערכת אישית וחינמית

אפליקציית Web/PWA בעברית ללימוד עצמי של תמרורי ישראל. אין צורך בשרת, במסד נתונים או בתשלום חודשי.

## מה כלול

- מאגר מורחב של 394 פריטים: תמרורים, רמזורים, סימוני דרך, תמרורי אתרי עבודה וסמלים.
- חיפוש לפי מספר, שם, משמעות ופעולת הנהג.
- כרטיסיות זיכרון עם חזרה במרווחים.
- מבחנים של 5, 10, 20 או 30 שאלות.
- מבחן לפי קבוצה, טעויות קודמות, תמרורים חלשים או מועדפים.
- שמירת ציונים והתקדמות ב־Local Storage של הדפדפן.
- גיבוי ושחזור ההתקדמות בקובץ JSON.
- התקנה כאפליקציה ועבודה לא מקוונת לאחר טעינה ראשונה.

## פרסום ב־GitHub Pages

1. פתח את קובץ ה־ZIP והעלה את כל התוכן לתיקיית השורש של ה־Repository הקיים.
2. אשר החלפה של הקבצים הישנים.
3. ב־GitHub היכנס ל־Settings → Pages.
4. בחר `Deploy from a branch`, ענף `main`, תיקייה `/(root)`.
5. לאחר הפרסום, רענן את האתר. במקרה שהגרסה הישנה עדיין מוצגת, סגור את לשונית האתר ופתח אותה מחדש או נקה את נתוני האתר פעם אחת.

## הפעלה מקומית לצורך בדיקה

אין לפתוח את `index.html` ישירות. מתוך התיקייה הרץ שרת מקומי, למשל:

```bash
python -m http.server 8000
```

ואז פתח בדפדפן: `http://localhost:8000`

## מקורות והסתייגות

מבנה המאגר הושווה ללוח התמרורים הרשמי של משרד התחבורה, ספטמבר 2022. הנחיות ההצבה המעודכנות לשנת 2024 משמשות כמקור משלים. חלק ניכר מהאיורים נחתך מגיליון תמרורים לימודי ותיק; פריטים מאוחרים יותר מסומנים במערכת כ״איור לימודי סכמטי״ ואינם קובצי ייצור רשמיים.

המערכת נועדה ללימוד אישי בלבד. נוסח מחייב, פירוש משפטי, תחולה והצבה יש לבדוק במקור הרשמי ובדין העדכני.

## פתיחה מקומית

בגרסה 3 ניתן לפתוח את `index.html` ישירות לאחר חילוץ מלא של קובץ ה-ZIP.
המאגר מוטמע גם בקובץ `data/signs-data.js`, ולכן אינו תלוי בשרת מקומי.
לשימוש ב-PWA, התקנה ועדכונים מומלץ עדיין לפרסם ב-GitHub Pages.
